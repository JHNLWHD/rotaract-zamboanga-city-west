# 05 — Seasonal applications and interest list

**What to build:** Give annual recruitment a truthful seasonal CTA and provide a lightweight way for people to hear about the next intake.

**Blocked by:** None — can start immediately.

**Status:** blocked-on-interest-form-url

- [x] During intake, the site shows “Applications open” and links to the active application form.
- [x] Outside intake, the site shows “Applications closed — get notified next cycle.”
- [ ] The off-season Google Form collects only name and email plus explicit consent.
- [ ] The form explains its notification purpose and retention period.
- [ ] Interest-list entries are removed after each recruitment cycle unless the person opts in again.
